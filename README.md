# Content Automator

Automated content generation and workflow automation system built with Python.

## Tech Stack
- **Language**: Python 3.11+
- **Testing**: pytest
- **Environment**: virtualenv (`.venv`)
- **Documentation**: Living Docs architecture

## Quickstart

### 1. Environment Setup
Activate the virtual environment:
```powershell
.venv\Scripts\activate
```
Or in Bash:
```bash
source .venv/Scripts/activate
```

### 2. Testing
Run test suite:
```bash
pytest
```
